How It Works
1
Enter private inputs in the browser Age, income, or identity secret -- typed locally, never transmitted
2
Circuit files fetched from server WASM and zkey files downloaded once, cached permanently in browser
3
Proof generated locally via snarkjs Groth16 fullProve() runs in browser Web Workers -- private inputs used here only
4
Only proof + public signals sent to server POST /compliance/check -- no private data in the request
5
Server verifies cryptographically groth16.verify() checks the proof against the circuit's verification key
6
Nullifier stored in Redis Proof hash recorded -- same proof can never be replayed
